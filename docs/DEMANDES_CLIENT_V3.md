# Demandes client v3 (26/10/2026)

Ordre fixé par le client : **1. couleurs de la page d'accueil selon la charte, puis capture complète** ; ensuite les chantiers ci-dessous.

## 1. Page d'accueil
- Reprendre uniquement les couleurs (pas le design) : rendu épuré et simple, conforme à la charte (bleu marine #0B2D5B, vert #4CAF50, gris clair #E5E7EB, Montserrat / Allura).

## 2. Installation de l'application (maquette fournie)
- Écran « Installez Lien Parental sur votre iPhone / Android » : onglets iPhone (iOS) / Android, étapes numérotées illustrées (menu de partage Safari ou menu Chrome, « Sur l'écran d'accueil », confirmer « Ajouter »), bloc « Pourquoi ajouter l'application ? », bloc « Soutenez Lien Parental » (don), bouton « Continuer », mention « Vos données sont en sécurité ». Logo avec baseline, lien « Centre d'aide ».

## 3. Finances
- Renseigner le plus possible tout type de paiement (le type Dépense / Paiement du Journal est en place ; à compléter si besoin).

## 4. Guide Parent Guyane
- Fiches pratiques concrètes, par ex. « Ouvrir un livret / un compte pour mon enfant » : documents précis à apporter, pour éviter les déplacements inutiles.
- Administrable (voir §6).

## 5. Coffre-fort verrouillé
- Avant d'accéder au coffre-fort : saisir un code / mot de passe ou utiliser l'empreinte digitale / reconnaissance faciale (WebAuthn / passkey sur web et mobile).

## 6. Espace administrateur
- Guides parentaux : ajouter, modifier, supprimer, publier.
- Modèles de documents PDF : ajouter, modifier, supprimer, toutes les actions.
- Articles de blog : ajouter, modifier, supprimer, publier.
- Tableau de bord complet : graphiques, inscrits (évolution), revenus (abonnements, dons), activité, etc.

## 7. Calendrier
- Connexion Google Agenda : les rendez-vous créés dans Lien Parental s'ajoutent automatiquement à l'agenda Google de la personne.

## 8. Authentification
- Connexion et inscription avec Google.

## 9. Messagerie
- Historique des conversations, démarrer une nouvelle discussion.
- Les documents / photos envoyés dans une conversation s'ajoutent automatiquement au coffre-fort (idem pour les témoignages et autres pièces).
- Notes vocales directement depuis la messagerie.

## 10. Liaison des parents
- Lors de l'inscription, un parent peut ajouter l'autre parent, qui reçoit ses accès.
- Si les deux ont déjà un compte : synchroniser les deux espaces.
- Pouvoir ajouter plusieurs parents (familles recomposées).
