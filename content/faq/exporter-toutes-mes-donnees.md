---
title: "Comment exporter toutes mes données ?"
category: "Compte"
updatedAt: "25 octobre 2026"
---

Lien Parental vous permet de récupérer l'intégralité de vos données en un fichier, à tout moment. C'est votre droit à la portabilité (RGPD, article 20).

Les étapes :

1. Ouvrez "Réglages".
2. Appuyez sur "Exporter mes données".
3. Choisissez le format : PDF (lisible, pour archives papier) ou ZIP (fichiers d'origine + fichier JSON structuré).
4. Validez.

Lien Parental prépare l'export en tâche de fond. Pour un gros coffre, cela peut prendre quelques minutes. Vous recevez une notification quand il est prêt, et un lien sécurisé par e-mail valable 72 heures.

Contenu de l'export :

- Tous vos documents dans leur format d'origine, rangés par dossier.
- Votre journal au format texte et PDF.
- Vos témoignages au format PDF signé.
- Votre calendrier au format iCal (.ics).
- L'historique de vos échanges avec le Coach IA.

Un exemple concret : avant une audience, vous générez un PDF "Dossier JAF" numéroté. Avant de supprimer votre compte, vous générez un ZIP complet que vous conservez sur un disque externe.

Deux conseils pratiques :

- Chiffrez le ZIP si vous le stockez sur un cloud personnel.
- Conservez une copie physique (clé USB, disque dur) pour les documents critiques.

Pour toute question juridique sur l'archivage de preuves, consultez votre avocat.
